# Demo Questions

Use these questions during an interview demo.

Product questions:

- What problem does OpenDocuments solve?
- What are the main surfaces of the product?
- How is this different from a simple chatbot wrapper?

Architecture questions:

- Explain the monorepo structure.
- Why does most business logic live in `packages/core`?
- How do the CLI, Web UI, HTTP API, SDK, and MCP server share behavior?

RAG questions:

- How does the ingestion pipeline work?
- What retrieval techniques does OpenDocuments use?
- What is the difference between the fast, balanced, and precise profiles?

Security and operations questions:

- How are API keys handled?
- What security protections exist around SQL, FTS5, and workspace isolation?
- How can this be deployed for private documents?

Suggested opening question:

"What is OpenDocuments, and how is it architected?"
